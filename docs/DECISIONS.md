- 2026-11-08 — audio: Fully procedural audio, zero third-party sound files. Every SfxId is a synth recipe (src/audio/synth/sfx.ts) baked once at boot via OfflineAudioContext (~60 variants, ≈1.4 s desktop, off the main thread), so no licence entries, no download bytes and one coherent "paper, graphite, wet ink" sound language. Recorded sprites (Opus/WebM + AAC/M4A, picked by canPlayType with decode fallback) are still supported via src/audio/sprites.ts — set SPRITE and add licences; sprite ids override the synth per id.
- 2026-11-08 — audio: Mastering in the bake: loudness to a per-id LUFS target (BS.1770 K-weighted, gated), then a lookahead limiter (≤6 dB GR, 9 dB for hurt/bolt/scribble) holds peaks at -1 dBFS. Master bus ends in a DynamicsCompressor limiter (-2 dB, 20:1). Faders are square-law (0.5 ≈ -12 dB).
- 2026-11-08 — audio: Music is a composed generative score (src/audio/music/tracks.ts) on a 25 ms look-ahead scheduler: one leitmotif (A A A | D – F E | D) across title (D minor), explore (D Aeolian/Dorian pad + pencil-hatching texture, combat stems fade in by intensity), boss (D Phrygian, 3 phases add choir, pencil hats, brass) and cover (D major). Notes create one-shot nodes on the scheduler tick (unavoidable in Web Audio), never per animation frame.
- 2026-11-08 — audio: iOS: navigator.audioSession.type = 'ambient' (respects the silent switch, mixes with the player's music, like native games). `AudioEngine.mayBeMutedBySwitch` lets UI show a hint. Context is suspended on visibilitychange/pagehide and re-resumed on the next gesture after an "interrupted" state.
- 2026-11-08 — audio: install(ctx) also maps state:change → music track, boss:phase → boss intensity (0.34/0.67/1), game:pause → muffled music + silenced loops, and derives combat intensity from enemy spawn/reveal/death until anyone emits an explicit `music:intensity` for 'combat' (then the explicit driver wins). Both behaviours can be switched off via InstallOptions.
